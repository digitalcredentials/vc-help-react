# vc-help-react

In-Progress

A set of react components with contextual help content (text/images) for Verifiable Credentials.

This is primarily meant to be used in contextual help popups for VerifierPlus, but extracted here into a separate repository for possible shared use in the Learner Credential Wallet, and also by anyone wanting to provide contextual help for issues related to Verifiale Credentials.
